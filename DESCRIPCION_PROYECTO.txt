DESCRIPCIÓN GENERAL DEL PROYECTO
================================

Nombre: Pollería Don Pepito Web
Carpeta: Polleria Don Pepito
Tipo: Aplicación web SPA (Single Page Application) para una pollería ubicada en Ica, Perú.
Framework: Angular 22 (componentes standalone, change detection zoneless).
Lenguaje: TypeScript 6.
Estilos: SCSS con sistema de tokens, componentes con estilos encapsulados y estilos globales.
Backend opcional: Supabase (PostgreSQL + Auth + RLS).
Modo demostración: activo por defecto (useDemoFallback = true), funciona sin conexión a Supabase usando datos locales y localStorage.

El proyecto incluye tienda online, carrito, checkout, seguimiento de pedidos, cuentas de usuario, club de puntos, reservas de mesas y un panel administrativo completo.


TECNOLOGÍAS Y DEPENDENCIAS PRINCIPALES
======================================

- Angular 22.2: core, common, compiler, forms, router y platform-browser.
- @ng-icons/core y @ng-icons/lucide: iconografía SVG.
- @supabase/supabase-js: autenticación y acceso a datos remotos.
- chart.js: gráficos del panel administrativo y reportes.
- RxJS 7.8.
- Vitest 5: pruebas unitarias.
- jsdom: entorno de pruebas.
- Prettier: formato de código.
- TypeScript 6.
- Angular CLI 22 y @angular/build.

Comandos disponibles (package.json):
- npm start / ng serve: servidor de desarrollo en http://localhost:4200
- npm run build / ng build: compilación de producción en dist/
- npm run watch: compilación en modo desarrollo con recarga
- npm test / ng test: pruebas unitarias con Vitest

FUNCIONALIDADES DESTACADAS
==========================

- Catálogo de productos con categorías, búsqueda, filtros, precios, descuentos,
  etiquetas, nivel de picante y disponibilidad.
- Carrito persistente con cantidades, notas por producto, subtotal y delivery.
- Checkout con entrega o recojo, distritos de Ica, métodos de pago, canje de
  puntos y validaciones.
- Seguimiento de pedidos por código y estados.
- Registro e inicio de sesión con roles cliente/administrador.
- Club de puntos sin niveles: todos los miembros tienen los mismos beneficios.
  Se gana 1 punto por cada S/ 1 y 100 puntos equivalen a S/ 1 de descuento.
- Reservas de mesas y gestión de disponibilidad del salón.
- Panel administrativo con CRUDs, métricas, reportes y configuración.
- Integración opcional con Supabase y modo demo local automático.
- Diseño responsive con navbar móvil, carrito lateral y botón de WhatsApp.
- Mapa de ubicación con OpenStreetMap en Inicio y Contacto.
- Carga inicial optimizada con fuentes locales, precarga y pantalla splash.
- SEO básico: metadatos, Open Graph, Twitter Card, JSON-LD, sitemap y robots.

Zonas de delivery configuradas:
Ica, La Tinguiña, Parcona, San Juan Bautista, Los Aquijes y Tate.

- Estado actual verificado: npm run build y npm test -- --watch=false pasan correctamente.
